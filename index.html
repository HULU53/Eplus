01 / CORE

项目能做什么

从数据读取到答案解析，再到实验性的页面辅助流程，E+ 把分散的能力组织成一套可切换的 Android 工具。

ANSWER READER

一键读取并整理试卷答案

读取设备中已经下载的 e听说资源，解析试卷结构、题目顺序与答案内容，在一个列表中集中查看。

  • 本地文件读取与内容解析
  • 支持多题型答案展示与复制
  • 云端作业列表下载与缓存

CLOUD MODE

直接获取云端作业

PRIVACY

本地读取不上传文件

本地模式只在本机解析所选数据；云端模式仅通过 ETS100 接口获取账号下的作业资源。

02 / MODES

选择适合自己的读取方式

不同设备、权限与环境适合不同路径。选择模式即可查看它的适用场景、前置条件与风险边界。

推荐路径 SYS_READY / SHIZUKU

借助 Shizuku 稳定读取本地数据

通过用户主动授权的 Shizuku 服务执行文件读取命令，不需要 Root，适合希望读取本地已下载作业的设备。

适合本地作业读取
前置安装并启动 Shizuku
注意Android 版本与设备兼容性
启动 Shizuku→授予权限→选择模式→开始读取
在线作业 SYS_READY / CLOUD

通过 ETS100 接口获取云端作业

使用 ETS100 账号登录，在线拉取作业列表、下载资源并在本机完成解析，无需提前配置本地文件权限。

适合未下载完整本地资源
前置合法 ETS100 账号
注意可能顶掉官方客户端登录状态
登录账号→读取列表→下载解析→查看答案
兼容模式 SYS_DIRECT_READ

利用零宽字符直读设备目录

使用系统路径解析方式访问目标目录，不需要额外安装 Shizuku，但实际可用性取决于设备与系统版本。

适合兼容设备上的本地数据
前置基础文件与悬浮窗权限
注意不同设备可能提示不支持
检查可用性→完成授权→选择目录→解析答案
高权限 SYS_READY / ROOT

使用 Root 直接访问应用数据

设备完成 Root 后，E+ 可以通过高权限命令读取目标文件。能力最强，但需要自行理解设备安全风险。

适合已 Root 的设备
前置Magisk / SuperSU 等授权
注意设备安全与系统稳定性风险
检测 Root→允许授权→选择模式→开始读取
03 / WORKFLOW

从授权到答案，只保留必要步骤

界面围绕“先确认环境，再读取数据，最后查看结果”组织流程，减少反复切换应用和寻找文件的操作。

01

选择运行授权

根据设备条件选择云端、Shizuku、直读或 Root。

02

完成必要授权

按系统提示开启文件、悬浮窗、无障碍或账号权限。

03

读取并解析

扫描本地试卷或下载云端作业，在本机整理答案。

04

查看与使用

在答案页阅读、切换试卷，或复制作答参考内容。

04 / AUTOMATION LAB
实验性功能

自动答题研究模块

当前实现主要研究选择题自动定位与朗读题扬声器播放。它需要用户主动启用无障碍、悬浮窗、截图和系统语音能力，并逐题确认任务。

01

混合页面识别优先读取无障碍节点，文字不足时回退 ML Kit 中文 OCR。

02

选择题定位匹配题目与选项文本，只允许在屏幕内坐标执行点击。

03

朗读题输出使用系统 TextToSpeech，可控制媒体音量与播放状态。
